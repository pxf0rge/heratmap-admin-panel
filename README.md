> پورتال تحت وب Next.js برای مدیریت لایه‌های نقشه، ثبت شرکت‌ها و تایید اطلاعات شهرک صنعتی هرات.

---

## 🌟 Key Features / ویژگی‌های کلیدی

### English
- Interactive Leaflet GIS editing
- Enterprise verification workflow
- Responsive Tailwind CSS admin theme
- Zod schema validation

### فارسی
- ویرایش و ترسیم لایه‌های نقشه با Leaflet
- گردش‌کار تأیید مشخصات شرکت‌ها و کارخانه‌ها
- قالب ریسپانسیو مدرن با Tailwind CSS
- اعتبارسنجی دقیق داده‌ها با Zod

## 🚀 Getting Started / راه‌اندازی

1. **Clone the repository:**
   ```bash
   git clone https://github.com/pxf0rge/heratmap-admin-panel.git
   cd heratmap-admin-panel
   ```

2. **Install packages:**
   ```bash
   npm install
   # or
   pnpm install
   ```

3. **Run local dev server:**
   ```bash
   npm run dev
   ```
